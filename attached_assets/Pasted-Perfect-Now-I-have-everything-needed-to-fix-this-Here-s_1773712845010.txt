Root cause: Facebook stopped putting aria-label attributes on their form fields. Every field now has a <span id="_r_xx_">Label Text</span> and the interactive element (the <label role="combobox"> for dropdowns, or the <input>) carries aria-labelledby="_r_xx_" instead. Those _r_xx_ IDs are random and regenerate on every page load.
The fix — two changes:
fill-engine.js — Added two new functions:

findByLabelText(text) — searches all <span id> elements for matching visible text, then finds the associated interactive element via aria-labelledby or by walking up to the parent <label>
resolveElement() — a smarter version of waitFor that understands "fb-label:Year" style selector strings as a trigger to use text-based lookup instead of CSS

content.js — Updated all Facebook adapter selectors to lead with "fb-label:Vehicle type", "fb-label:Year", etc., with the old aria-label selectors kept as fallbacks. So if Facebook ever puts aria-labels back, it still works.
